# packet-tracer-campus-security-enterprise-network-design
Secure campus network design in Cisco Packet Tracer featuring multi-VLAN segmentation (Students, Lecturers, Finance, ICT Admin, and Internal Servers), inter-VLAN routing on a Layer 3 Core Switch, an isolated DMZ for public web services, and Edge Router perimeter security with NAT/PAT and Access Control Lists (ACLs).
